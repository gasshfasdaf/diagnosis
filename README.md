# Диагностика PWA

Клиент-серверное PWA для диагностов автодилера. Чек-лист приёмки автомобиля на склад.
MVP-версия: полностью автономная (без бэкенда), данные хранятся в `localStorage`, работает оффлайн.

## Демо

- **Промокод**: `123`
- **Хостинг**: GitHub Pages (HTTPS, PWA, установка на домашний экран)

## Быстрый старт (локально)

```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve
